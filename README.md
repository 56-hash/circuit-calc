# 회로 손글씨 계산기 (PWA)

삼성 노트에서 푼 수식 영역을 **AI Select → 공유** 하면, 손글씨를 인식(LLM 비전)하고
자체 계산 엔진(복소수·페이저·행렬·solve)으로 **결정적으로 계산**합니다. LLM은 "옮겨 적기"만 하고 계산은 하지 않습니다.

## 설치 (갤럭시 탭 S10 FE+)
1. 이 폴더(`index.html`이 있는 곳)를 **HTTPS** 정적 호스팅에 올립니다 (GitHub Pages / Netlify / Cloudflare Pages 등, 상대경로라 하위 경로도 OK).
   - 로컬 확인: `npm install && npm start` → http://localhost:8080 (공유 수신은 HTTPS에서만 동작)
2. 탭의 Chrome(또는 삼성 인터넷)으로 접속 → 메뉴 → **홈 화면에 추가 / 앱 설치**.
3. 앱 → **설정** → Anthropic API 키 입력 (키는 이 기기의 localStorage에만 저장, 인식 요청 때 api.anthropic.com 으로만 전송).
4. 삼성 노트 → AI Select로 영역 선택 → **공유** → "회로 손글씨 계산기".

그 외 입력: 이미지 선택, 붙여넣기, 필기 캔버스, 직접 입력, 데모 버튼(키 불필요).

## 사용
- **직렬**: 줄마다 ▶ 로 하나씩 실행(변수·`Ans` 유지). **일괄**: 체크한 줄을 모아 의존 순서대로 대입 → 연립식 동시 풀이 → 식 계산.
- 줄을 눌러 인식 오류를 고칠 수 있고, 신뢰도 낮은 줄은 강조됩니다. 값이 없는 변수는 "값 입력"으로 즉시 지정.
- 결과는 직교/극/둘 다, 공학 표기(k, m, µ…), 유효숫자 설정 가능. 기록은 30일 보관.

## 입력 문법 요약
| 의미 | 예 |
|---|---|
| 복소수 | `3+j4`, `(1+j)^2` |
| 페이저(극형식) | `10@30deg`, `10∠30°` (기본 DEG, 상단 토글) |
| 병렬 | `R1||R2`, `(3+j4)||(6-j8)` |
| SI 접두 | `4.7k`, `10u`, `2.2n` (단위 Ω V A F H Hz W s 는 무시) |
| 이전 결과 | `Ans`, `#2` |
| 여러 문장 | `a=3; b=4; sqrt(a^2+b^2)` |
| 행렬 | `[[1,2],[3,4]]`, `inv(...)`, `det(...)` |
| 방정식 | `2x+3=11` (단일 미지수), 일괄 모드의 연립식, `solve(eq1, eq2, x, y)` |
| 함수 | sin cos tan asin… exp ln log sqrt abs arg conj re im dB sum prod int diff |
